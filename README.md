### 📖 Description
Locastion est une application web dynamique permettant la gestion et la location de voitures en ligne. Le projet inclut une partie client et une partie administrateur complète.

### ✨ Fonctionnalités

**Côté Client:**
- 🔐 Inscription / Connexion sécurisée (login_register)
- 🚙 Consultation du catalogue de voitures (service)
- 📄 Détails de chaque véhicule
- 📞 Page Contact & About
- 📅 Système de réservation

**Côté Admin:**
- 👑 Dashboard Admin (admin_page.php)
- ➕ Ajout / Suppression / Modification des véhicules
- 👥 Gestion des utilisateurs et des réservations
- 📁 Upload d'images

### 🛠️ Technologies Utilisées
- **Backend:** PHP Native
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
- **Base de données:** MySQL
- **Serveur:** Apache (XAMPP / WAMP)

### 🚀 Installation en Local
1. Cloner le repo: `git clone https://github.com/dahbia15/locastion-site.git`
2. Déplacer le dossier dans `htdocs` (XAMPP)
3. Importer la base de données `.sql` dans phpMyAdmin
4. Configurer `include/config.php` avec vos identifiants DB
5. Lancer sur `http://localhost/locastion-site`
